## Why

多模态 Agent 必须在当前模型调用中读取图片或文档，但部分应用不能把原始二进制长期写入会话数据库。现有历史处理器只影响模型调用前的上下文，不能约束 `ChatMessage` 的持久化内容。

## What Changes

- 为 Agent 会话增加可选的持久化处理器配置。
- 在用户消息和最终消息写入会话前运行处理器，事件流和当前模型调用仍保留原始内容。
- 提供通用多模态引用投影器，把二进制和文件 URL 替换为不含原件或 URL 的文本引用。
- 未配置处理器时保持现有完整多模态持久化行为。

## Capabilities

### New Capabilities

- `message-persistence-projection`: 应用可独立控制模型当前输入与长期会话持久化表示。

## Impact

- 修改会话配置、Agent 消息持久化和 RunHandle 最终消息保存逻辑。
- 新增单元测试；不改变默认行为或协议事件内容。
